# Maa Durga Library

React + Vite app for the existing Supabase project `bgxxezwyifidnpsunymx`.

## 1. Configure environment

1. Copy `.env.example` to `.env` (or `.env.local`).
2. In Supabase Dashboard, open **Maa Durga Library** → Project Settings → API.
3. Copy the project's publishable/anon key into `VITE_SUPABASE_ANON_KEY`.
4. Keep the URL set to `https://bgxxezwyifidnpsunymx.supabase.co`.
5. Never use a `service_role` or secret key in this frontend.

## 2. Install and run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## 3. Database and security

The app expects the existing `public.library_management` table and `public.remaining_seats` view. It does not create or seed tables.

**Important:** RLS is enabled on the members table. Configure administrator-only policies before expecting CRUD queries to work. Do not create a blanket policy that gives every authenticated user access. Create the admin user in Supabase Auth and implement an administrator allow-list / `library_admins` table with policies before using real member data. The app does not contain a service-role key.

## 4. Deployment

Deploy the Vite project to Vercel and add the two `VITE_...` environment variables in Vercel Project Settings → Environment Variables. Redeploy after adding them. Configure Supabase Auth's Site URL and Redirect URLs to match the deployed domain.

## Notes

- Seat numbers are 1–89.
- `expiry_date` is generated by PostgreSQL and is intentionally omitted from insert/update payloads.
- The app does not insert demo members into the production database.
